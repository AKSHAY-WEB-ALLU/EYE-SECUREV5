EYE SECURE QUOTATION BUILDER V4

NEW IN V4
- AKSHAY SOFTWARES credit appears in the website top bar only; it is removed from the quotation/PDF document.
- Use "Arrange objects" in the live preview to move individual text/object elements with mouse or touch. Positions are saved with the document when you click Save.
- Use "Edit text" separately to change text in the preview.
- Dark mode / Light mode switch in the website top bar. Theme preference is remembered in this browser.
- Existing V3 features retained: dashboard, quotations and bills, saved customers/products, history, analytics, discounts, optional GST, and print/PDF.

RUN
1. Extract this ZIP to a permanent folder.
2. Install Node.js LTS if needed: https://nodejs.org/en/download
3. Double-click start.bat.
4. The app opens at http://localhost:4173. The terminal also prints a LAN address such as http://192.168.1.5:4173.
5. Connect your phone/tablet to the same Wi-Fi as the PC and enter that LAN address in its browser.
6. If Windows Firewall asks, allow Node.js on Private networks only. If no prompt appears, allow inbound TCP port 4173 for Private networks in Windows Defender Firewall.
7. Keep the terminal window open while using the app.

DATA
Records are stored in the data folder. Back up the entire data folder regularly.
If upgrading from V3, copy your old data/*.json files into this version's data folder before starting V4 (make a backup first).

NOTES
- This is a local-network application, not publicly hosted. Devices must be on the same Wi-Fi/LAN. Do not port-forward it to the public internet; it has no login/authentication.
- Preview arrangement is object/text-level drag positioning; complex overlapping positions may need manual adjustment, especially for printed A4 pages.
- For best PDF output, use the desktop/PC preview and choose Print > Save as PDF.
